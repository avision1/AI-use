Windows12 is this project's working name for a Debian KDE desktop. It is independent of Microsoft. This preview combines a familiar taskbar, searchable application menu and everyday tools.

Start with what you know

Your desktop

Open the bottom-left application menu to search for apps. Dolphin is your file manager; Discover is your software center. Double-click to open files. Find browser downloads in the Downloads folder. In Dolphin, press Ctrl + L to enter a folder path.

Your documents

Open Microsoft 365 (web) from the menu for online Office. Use LibreOffice for offline documents. They have different features and formatting behavior.

Your settings

Open System Settings for displays, Wi-Fi, sound, printers and accessibility. Use Discover to install software and apply updates. Hardware support depends on available Linux drivers.

Office, with clear expectations

The menu provides browser launchers for Word, Excel, PowerPoint, Outlook, OneDrive and Teams. They open the official Microsoft websites. Chromium provides a separate app-style window; Firefox opens a normal browser window. Login, internet access, account type and Microsoft's service terms apply. The launcher never asks for or stores your password.

Open Microsoft 365 · Open Outlook · Open OneDrive

On a small screen or at high zoom, scroll the table sideways. Keyboard users can focus the table and use the arrow keys.

Compatibility in this development preview
WorkflowWhat to expect
Common document editingOffice web: partial desktop Office functionality. LibreOffice: offline alternative; complex formatting can change.
Excel VBA and desktop add-insNot provided by these web launchers. Excel web cannot run or edit VBA macros.
OneDrive filesWeb access only. Windows Files On-Demand and automatic folder synchronization are not implemented.
Windows .exe / .msi appsNo universal compatibility. Wine integration is a later task; no Windows application has yet been validated for this preview.
Games and Windows driversNo promise of anti-cheat, driver, DirectX or game compatibility. Windows kernel drivers cannot be installed as Linux drivers.
BitLocker, Windows Hello and Active DirectoryWindows feature parity is not implemented. Do not migrate an encrypted installation or managed work device based on this preview.

Useful shortcuts

Alt + Tab switches windows. Alt + F2 opens the command/search runner. Use the application menu for session, restart and shutdown controls. Shortcut behavior is supplied by KDE and should be verified on your hardware.

Try it before installing

Live mode lets you explore without an installation. The Debian installer is available from the live desktop. This project's installer and recovery path must pass disposable virtual-machine tests before a release is recommended. No physical installation has been tested.

This help page works offline. External services require a network connection. The project does not redistribute Microsoft Office or grant a Windows/Microsoft 365 license.
